## Exact SQL Definition

The package is a mixed-source count bundle, not a single-table metric:

```sql
with product_counts as (
  select
    count(*) filter (where is_active) as active_products,
    count(*) as real_products
  from public.products
),
merchant_registry as (
  select
    count(*) as merchant_registry_rows
  from public.merchants
)
select
  now() at time zone 'utc' as collected_at_utc,
  pc.active_products,
  pc.real_products,
  mr.merchant_registry_rows as merchants
from product_counts pc
cross join merchant_registry mr;
```

## Field Definitions

- `active_products`: exact count of rows in `public.products` where `is_active = true`
- `real_products`: exact count of all rows in `public.products`
- `merchants`: exact count of all rows in `public.merchants`

Important definition boundary:

- `merchants` in this package is a merchant-registry row count, not the CEO report's catalog-backed merchant metric.
- The CEO report's canonical merchant metric is `count(distinct merchant_id)` from `public.products`, which last confirmed at `15,070` in [docs/daily-ceo-report-input-2026-05-26-oracle.md](/paperclip/instances/default/projects/177bc805-e3c8-4336-84cb-8e1e482d5a17/18221361-973a-493e-9e19-4c43b7a1c6eb/_default/docs/daily-ceo-report-input-2026-05-26-oracle.md).

## Why This Is The Correct Source Definition

The workspace contains direct evidence for each field family:

1. The canonical exact Oracle product package already uses `public.products` with `count(*) filter (where is_active)` and `count(*)`.
2. Oracle's exact merchant package already distinguishes catalog-backed merchants from the larger merchant registry and shows that `public.merchants` is a different metric family.
3. The public `GET /v1/catalog/stats` snapshot on `2026-05-28` reported `total_merchants = 64,812`, which matches the registry-scale merchant family and not the catalog-backed merchant definition.

Taken together, the `2,797,824 / 2,812,997 / 64,812` bundle is best understood as:

- exact `public.products` counts for active and total products
- paired with a merchant-registry count from `public.merchants`
